# Library
 Консольное приложение на C++ для автоматизации учета книжного фонда и работы с читателями городской библиотеки. Проект спроектирован с использованием принципов модульной архитектуры и разделением на заголовочные файлы и файлы реализации.
Функционал программы
1. Управление каталогом книг: Добавление новых изданий, просмотр полного списка книг и удаление позиций из системы.
2. Учет и регистрация читателей: Добавление новых пользователей, хранение номера читательского билета, просмотр списка зарегистрированных читателей и редактирование персональных данных.
3.  Оформление выдачи книг на руки читателям с автоматическим контролем доступности экземпляров и запретом выдачи нескольких книг одному читателю, а также регистрация возврата.
4. Нахождение конкретной книги по уникальному ID или названию, а также поиск читателей по номеру билета или имени.
5. Вывод общих данных по библиотек.
